## Assessment
**Substantive and in-scope.** The authentic PDF (~55 KB, min. Heinen, Financiën, kenmerk 2026Z13066, received
**3 Sep 2026**) answers questions about a corruption probe into an Albanian resort routed through Dutch
letterbox firms. It cites the EU AML package by number — Reg (EU) **2024/1624** (antiwitwasverordening) and Dir
(EU) **2024/1640** (AMLD6) — so this is the tracked file, **not** the criminal-law 2018/1673 sibling. It
carries four new facts for the NL transposition workstream:

1. **Iwt submission timing:** the implementation bill is expected to be **submitted to the Tweede Kamer before
   the end of the calendar year (2026)** — advances the repo's "at the Raad van State for advice" marker.
2. **Member-state option USED:** the cabinet will use a lidstaatoptie requiring **verscherpt cliëntenonderzoek
   (EDD)** for **domicilieverleners and broader trust-service providers**, given inherent risks; necessity to be
   re-evaluated some time after entry into force (Toegezegd, bijlage 'Appreciatie beleidsopties', Kamerstukken
   II 2025/26, 32 545, nr. 229). This *adds* burden — a concrete counter-point to the "lastenluw" framing.
3. **Member-state option DECLINED:** the cabinet **will not** lower the UBO threshold to **15%** in high-risk
   situations, "in lijn met de kabinetsinzet om administratieve lasten te verminderen"; keeps "25% or more" with
   risk-based supervision.
4. **Negotiating record:** NL pushed during the package negotiations for a **registration duty for
   domicilieverleners**, now part of the package.

Confirms the package applies from **10 July 2027** (footnote 14 of the answer) — already recorded.
