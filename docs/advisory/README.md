# Advisory opinions

Digests of advisory-body opinions on the package, one file per opinion.

The package is **adopted**, so the classic OLP advisory opinions (EDPB/EDPS, ECB, EESC, CoR on the proposals)
are historical. The live equivalent is **stakeholder/advisory input into AMLA's Level-2/3 consultations** —
tracked in [`../amla-pipeline.md`](../amla-pipeline.md) and [`../stakeholders.md`](../stakeholders.md).

No standalone advisory digest is tracked yet. Add one here (e.g. `<body>-<ref>.md`) if a relevant opinion on
the implementing measures appears, and link it from [`../institutional-positions.md`](../institutional-positions.md).
